# Kintion 0.2 — «Делюсь»

[English version](RELEASE_NOTES.md)

Публичная 0.2 добавляет совместный доступ: пригласите другой аккаунт по нику и откройте ему выбранные группы для просмотра или правки. Гость видит записи этих и вложенных групп; остальные записи и связи остаются закрытыми.

- **Аккаунты и приглашения.** По умолчанию регистрация по приглашению администратора. Можно разрешить приглашения всем пользователям, открыть регистрацию или создавать аккаунты вручную. Каждый аккаунт получает свой дашборд; приглашение в чужой дашборд принимается отдельно.
- **Правка гостем.** Гость правит доступные записи групп, где у него есть право правки. Владелец отдельно разрешает создание записей; созданное получает метку специальной группы гостя. Права можно менять, гостя — убрать из дашборда.
- **Содержимое карточек.** Форматированный текст с предпросмотром, вложенные файлы, свои блоки полей и просмотр изображений в полном размере.
- **Даты и эры.** Порядок эр, границы лет и обратный счёт, текущий год вымышленного мира — в настройках дашборда.
- **Видимость.** Права действуют в дереве, списках, карточках, поиске и при скачивании файлов. Владелец видит весь журнал дашборда, гость — только свои действия.
- **Поставка.** CI проверяет Go с PostgreSQL, фронтенд и свежую установку Compose через Playwright. Тестовые ветки также собирают образы amd64 и arm64 без публикации; выпуск образа зависит от успешного CI.

## Ограничения версии

Гость пока не удаляет записи и не управляет группами, шаблонами, эрами или доступом. Уход из дашборда — через API либо удаление гостя владельцем. Уведомления о новых выдачах и режим без чувствительных данных ещё не реализованы: сам флаг чувствительности ничего не скрывает. Импорт/экспорт, GEDCOM, сеть и таймлайн — в планах. Большие демо-наборы в этот выпуск не входят.

## Обновление с 0.1

Сохраните вместе базу и файлы, затем разверните 0.2. Новые миграции применятся при запуске. Старые дашборды автоматически никому не открываются; регистрация по умолчанию — `invite`. Не запускайте старый образ с обновлённой базой: для возврата к старой версии потребуется откат миграций по инструкции или восстановление бэкапа.
